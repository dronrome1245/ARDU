# Инвентарь имеющихся компонентов

Дата последнего обновления: 2026-09-05

Это реестр **того, что физически есть у владельца**. Он не равен BOM финальной лампы: ненужные для ARDU детали тоже сохраняются здесь.

Обозначения:

- ✅ идентификация уверенная;
- 🔵 нужно проверить номинал/исправность/точную модификацию;
- `основа` — кандидат в финальную лампу;
- `стенд` — полезен при разработке;
- `резерв` — пригодится только при альтернативной схеме;
- `не нужен` — не требуется базовой архитектуре ARDU.

## Что особенно полезно для ARDU уже сейчас

1. Два Nano — можно иметь основной и резервный/стендовый экземпляр.
2. YP-8 может закрыть 3,3 В для ESP8266, если пройдёт измерительную проверку.
3. Электролит порядка 1000 мкФ потенциально закрывает рекомендованный буфер питания WS2812B, если его напряжение подходит.
4. Breadboard + USB Mini-B позволяют собирать и прошивать стенд без новых покупок.
5. LCD + PCF8574 может упростить локальную диагностику, но добавлять его в финальную лампу без необходимости не следует.

## Правило дальнейшего пополнения

Каждую новую деталь по фото заносить сюда до выводов о закупке. Если одна и та же плата снята с двух сторон или крупным планом, не увеличивать количество автоматически.
