# Источники и лицензии

## AlexGyver ColorMusic

Страница проекта:

https://alexgyver.ru/colormusic/

Исходный код:

https://github.com/AlexGyver/ColorMusic

Использование в ARDU:

- архитектурная база режимов светомузыки;
- VU-метры;
- частотные режимы;
- анализатор спектра;
- логика параметров эффектов;
- идеи автокалибровки и хранения настроек.

Лицензия исходного репозитория: MIT License.

Copyright исходного проекта: `Copyright (c) 2018 AlexGyver`.

При переносе исходного кода в ARDU необходимо сохранять copyright notice и текст MIT License для копируемых/существенно адаптированных частей.

## AlexGyver Dawn Clock

https://alexgyver.ru/dawn-clock/

Использование в ARDU:

- концепция будильника-рассвета с постепенным увеличением яркости до заданного времени.

Конкретный код не считается перенесенным, пока он фактически не добавлен в репозиторий и не проверены его лицензионные условия.

## Пользовательские исходные материалы

При инициализации проекта использованы предоставленные владельцем материалы:

- `Распиновка.docx`;
- `Промпт на объединение скетча.docx`;
- `Светомузыка.docx`;
- `Будильник.docx`;
- `Команды для блютуза.txt`;
- `Ответ по калибровке.txt`;
- `Тест микрофона с хлопками.txt`;
- `Конденсаторы.docx`;
- `Схема-Модель.pdf`;
- фотографии имеющегося ESP8266MOD и компонентов.

Эти материалы используются как исторический контекст проекта. При конфликте нескольких старых вариантов окончательное решение фиксируется отдельным архитектурным решением и в актуальной схеме.

Лицензия собственного нового кода владельцем репозитория пока не выбрана. Поэтому файл `LICENSE` для ARDU не создается автоматически.
