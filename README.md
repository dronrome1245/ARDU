# ARDU — потолочная светомузыка

Проект адаптации идей AlexGyver ColorMusic под круглую потолочную лампу с адресной лентой WS2812B, микрофоном внутри светильника и управлением со смартфона.

## Цель

Собрать систему из уже имеющихся компонентов без обязательной покупки нового контроллера. Основной целевой канал управления — Wi‑Fi. Существующая Bluetooth-логика и короткий текстовый протокол сохраняются как база и резервный путь.

## Аппаратная база

- Arduino Nano — основной контроллер реального времени для аудиоанализа, световых режимов, RTC и управления WS2812B.
- ESP8266MOD AI-THINKER — имеющийся Wi‑Fi-модуль; рассматривается как сетевой шлюз между мобильным приложением и Nano.
- MAX9814 — микрофон с АРУ, источник аудиосигнала из помещения.
- DS3231 — часы реального времени для будильника-рассвета.
- WS2812B — адресная светодиодная лента, размещаемая по окружности потолочной лампы.
- HC-05 — ранее использовавшийся Bluetooth-модуль; может оставаться резервным интерфейсом на этапе миграции.

## Архитектурный принцип

Не переносить сразу весь проект с AVR на ESP8266. Сначала сохранить проверенную Nano-часть и отделить транспорт управления от логики эффектов: приложение → Wi‑Fi → ESP8266 → UART → Arduino Nano → свет/звук/RTC.

Такой подход позволяет повторно использовать логику ColorMusic и уже созданный Bluetooth-протокол, заменив прежде всего канал связи.

## Статус

Репозиторий находится на стадии архитектурной инициализации. Следующая техническая задача — проверить питание, прошивку и устойчивую UART-связь имеющегося ESP8266MOD, после чего зафиксировать сетевой режим и начать перенос команд приложения.
