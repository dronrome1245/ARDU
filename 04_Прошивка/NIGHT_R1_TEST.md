# ARDU — NIGHT R1 hardware test

Дата: 2026-09-26

## Цель

Проверить минимальный ночник до добавления расписания:

- постоянный HSV-цвет;
- малая яркость;
- ON/OFF;
- сохранение HUE/SAT/BRIGHTNESS/POWER во внутренней EEPROM Nano;
- восстановление состояния после reset.

## Defaults

На чистой EEPROM:

- POWER=OFF
- HUE=24
- SAT=180
- BRIGHTNESS=18

Defaults взяты из текущего примера API v1 для ночника. POWER по умолчанию OFF, чтобы первая загрузка тестовой прошивки не включала ночник неожиданно.

## Тест

После Verify/Upload:

```
STATUS
ON
HUE 24
SAT 180
BRIGHT 18
STATUS
```

Визуально должно быть спокойное постоянное свечение низкой яркости.

Параметрический тест:

```
HUE 0
HUE 96
HUE 24
SAT 255
SAT 80
SAT 180
BRIGHT 2
BRIGHT 40
BRIGHT 18
```

Все изменения должны происходить сразу.

## Persistence ON

Оставить:

```
ON
HUE 24
SAT 180
BRIGHT 18
```

Нажать Reset Nano.

После старта:

- POWER=ON
- HUE=24
- SAT=180
- BRIGHTNESS=18
- SAVED=YES

Кольцо должно самостоятельно восстановить ночник.

## Persistence OFF

```
OFF
```

Нажать Reset ещё раз.

Норма:

- POWER=OFF
- SAVED=YES
- кольцо остаётся выключенным.

## UART regression

Когда ночник включён, несколько раз подряд отправить `STATUS`. Ошибок `UNKNOWN_COMMAND` из-за FastLED быть не должно.

## Что не входит в R1

Расписание включения/выключения ночника. В проекте оно обозначено как дополнительная функция после основной реализации ночника.
