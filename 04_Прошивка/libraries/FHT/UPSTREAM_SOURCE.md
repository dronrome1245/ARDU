# FHT — upstream source

Неизменённая копия библиотеки FHT из официального репозитория AlexGyver ColorMusic.

- upstream: `AlexGyver/ColorMusic`
- pinned commit: `a3f94de053d431f15282c2f67681b77ab66c30ae`
- original path: `libraries/FHT/`
- ARDU path: `04_Прошивка/libraries/FHT/`

Назначение: воспроизводимая компиляция поздней официальной ColorMusic без подмены API другой FHT-библиотекой.

Для Arduino IDE папку `FHT` можно скопировать целиком в пользовательскую папку `Arduino/libraries/`. Исходный API: `#include <FHT.h>`, `fht_run()`, `fht_mag_log()`.

Файлы и примеры сохранены под исходными именами. Лицензия upstream сохранена как `UPSTREAM_LICENSE.txt`.
