# ARDU — сравнительный стенд MAX4466

Дата: 2026-09-22

## Цель

Проверить имеющийся MAX4466 отдельно от проблемной AC-развязки MAX9814/A2/A3.

Это **не замена MAX9814 в архитектуре**, пока сравнительный тест не пройден.

## Основание

- В инвентаре есть MAX4466 с регулируемым gain.
- MAX4466 работает от 2.4–5.5 V и имеет rail-to-rail output.
- В AlexGyver Community/FireEdition MAX4466 отмечен как удобный для тестирования благодаря регулируемому выходному диапазону.
- Для MAX4466 в обсуждении рекомендовалось не повторять проблемную конденсаторную разводку вслепую, а использовать резистивное подключение и сначала измерить DC.

## Подключение первого сравнительного теста

Используем четыре имеющихся 4.7 kΩ как две пары по 9.4 kΩ.

```text
MAX4466

VCC ───────────────── Nano 5V
GND ───────────────── Nano GND

OUT ── 4.7k ── 4.7k ── Nano A2
  │
  └── 4.7k ── 4.7k ── Nano A3
```

На этом тесте:

- **не ставить** 100 µF в сигнальную линию;
- **не ставить** 103/10 nF между A2 и A3;
- **не подключать** внешний AREF;
- **не подключать** A0;
- AREF в скетче = DEFAULT (~5 V);
- DC offset MAX4466 вычитается программно только перед FHT.

## Gain MAX4466

Начинать с малого усиления. Направление вращения подстроечника не фиксировать по памяти: разные модули могут иметь другую ориентацию.

Правильный уровень определяем по ADC:

- в тишине среднее A2/A3 ожидается примерно в средней части шкалы, не у 0 и не у 1023;
- при громком звуке MIN/MAX должны заметно расходиться;
- значения не должны устойчиво упираться в 0 или 1023.

## Прошивка

`04_Прошивка/nano_max4466_test/nano_max4466_test.ino`

Board:
- Arduino Nano;
- ATmega328P (Old Bootloader);
- Serial 115200.

## Первый тест

В тишине:

```text
STATUS
ADC2
ADC3
ADC2FAST
ADC3FAST
```

Если fast ADC не насыщается, выполнить:

```text
CALF
FREQ
```

Затем проверить 2 / 5 / 8 kHz командами `FREQRAW` и `FREQ`.

## Критерий успеха

1. A2/A3 не saturate при fast ADC.
2. CALF подавляет тишину.
3. 2 kHz → LOW, 5 kHz → MID, 8 kHz → HIGH.
4. Gain можно отрегулировать без изменения AREF.


## Первый аппаратный результат 2026-09-22

Получено при текущем стенде через последовательные 9,4 kΩ:
- ADC2 AVG=7 MIN=1 MAX=12;
- ADC3 AVG=8 MIN=4 MAX=12;
- ADC2FAST AVG=8 MIN=4 MAX=14;
- ADC3FAST AVG=8 MIN=4 MAX=15.

Для типичного MAX4466 breakout это ненормально низкий DC уровень: официальный Adafruit breakout имеет DC bias около VCC/2 и допускает прямое подключение OUT к ADC микроконтроллера без разделительного конденсатора.

Поэтому **до дальнейшего FHT не менять gain и не делать CALF**. Сначала измерить мультиметром непосредственно на модуле:
1. VCC→GND;
2. OUT→GND в тишине.

Если OUT≈VCC/2, убрать диагностические 9,4 kΩ ветви и перейти на прямое OUT→ADC. Если OUT около 0 V, сначала проверить питание/распиновку/исправность самого MAX4466.


## Изоляционный тест MAX4466

После измерения `VCC≈5,1 V`, `OUT≈0 V` дальнейший FHT остановлен.

Полностью отключить OUT от обеих ветвей 9,4 kΩ и от Nano. Оставить только:

```text
MAX4466 VCC -> 5V
MAX4466 GND -> GND
MAX4466 OUT -> никуда
```

При включённом питании измерить прямо на модуле:
- VCC→GND;
- OUT→GND.

Если OUT поднимется примерно к VCC/2, внешний стенд тянул выход вниз. Если OUT останется около 0 V, проверять распиновку/пайку/исправность MAX4466.


## Коррекция после изоляционного теста

Изолированный MAX4466 дал `OUT=2,55 V` при `VCC=5,1 V`, поэтому модуль исправен.

Предыдущую схему с двумя последовательными ветвями 9,4 kΩ **не использовать дальше** для первичного теста.

Новый минимальный стенд:

```text
MAX4466 VCC -> Nano 5V
MAX4466 GND -> Nano GND
MAX4466 OUT -> Nano A2
Nano A3     -> не подключать
AREF        -> не подключать
```

Скетч остаётся с DEFAULT AREF (~5 V). Сначала проверить только `ADC2` и `ADC2FAST`. Если среднее будет около половины шкалы и без saturation, затем отдельно подключать второй вход/частотный тракт.


## Прямой OUT→A2: первый результат

При прямом подключении без резисторов:
- ADC2=244 (208..293);
- ADC2FAST=230 (199..286).

Saturation исчез. Но результат ниже ожидаемого для ранее измеренного OUT=2,55 V. До FHT измерить мультиметром при подключённой Nano:
- MAX4466 OUT→GND;
- Nano A2→GND.

При прямом проводе значения должны совпадать.
