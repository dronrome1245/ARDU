# Stable IDs режимов ARDU

Дата: 2026-09-06

Эти ID используются между прошивкой, ESP8266 API и приложением. Пользовательские названия можно менять без изменения ID.

## Обычное освещение

- `L01` — обычный постоянный белый свет двух колец

## Светомузыка

- `M01` — VU градиент
- `M02` — VU радуга
- `M03` — 5 полос
- `M04` — 3 полосы
- `M05` — 1 полоса / выбранная частотная группа
- `M08` — бегущие частоты
- `M09` — анализатор спектра

`M06` retired по решению владельца 2026-09-27 и не переиспользуется. `M07` не используется как музыкальный ID: исходная «цветная подсветка» перенесена в фоновые эффекты.

## Фон

- `F01` — постоянный цвет
- `F02` — плавная смена цвета
- `F03` — бегущая радуга

## Подрежимы частот

- `three` — 3 частоты
- `low` — низкие
- `mid` — средние
- `high` — высокие

## Верхние разделы

- `off`
- `light`
- `music`
- `ambient`
- `night`
- `alarm`

Правило: ID после начала реализации не переименовывать без миграции сохранённых настроек и API.

## Актуальный статус F02/F03 и идея P01…P12 — D-104 (2026-10-08)

- F01 — остаётся в целевой модели «Фон» (ручной постоянный цвет).
- F02/F03 — **не нужны для будущего user-facing набора по решению владельца**. Их ID уже заняты в текущем firmware/API и не переименовываются/не переиспользуются без миграции.
- В действующем исходном коде F02/F03 по-прежнему присутствуют; на этом шаге ничего не удалялось.
- Рабочие обозначения будущих пресетов `P01…P12` описаны как **идея**, НЕ stable IDs в [AMBIENT_PRESETS_CONCEPT.md](AMBIENT_PRESETS_CONCEPT.md).
