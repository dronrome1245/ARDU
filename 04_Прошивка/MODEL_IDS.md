# Stable IDs режимов ARDU

Дата: 2026-09-06

Эти ID используются между прошивкой, ESP8266 API и приложением. Пользовательские названия можно менять без изменения ID.

## Светомузыка

- `M01` — VU градиент
- `M02` — VU радуга
- `M03` — 5 полос
- `M04` — 3 полосы
- `M05` — 1 полоса / выбранная частотная группа
- `M06` — стробоскоп
- `M08` — бегущие частоты
- `M09` — анализатор спектра

`M07` не используется как музыкальный ID: исходная «цветная подсветка» перенесена в фоновые эффекты.

## Фон

- `F01` — постоянный цвет
- `F02` — плавная смена цвета
- `F03` — бегущая радуга

## Подрежимы частот

- `three` — 3 частоты
- `low` — низкие
- `mid` — средние
- `high` — высокие

## Верхние разделы

- `off`
- `music`
- `ambient`
- `night`
- `alarm`

Правило: ID после начала реализации не переименовывать без миграции сохранённых настроек и API.
