# Нейросеть: начни отсюда

Этот файл — обязательная точка входа для любой нейросети в новом чате по проекту ARDU.

## 1. Что это за проект

ARDU — проект двух синхронных круглых потолочных светильников на WS2812B для обычного освещения, светомузыки, фоновых эффектов, ночника и будильника-рассвета с управлением со смартфона по Wi‑Fi.

Отдельные точечные светильники комнаты сохраняются, но ARDU также имеет собственный режим обычного освещения на двух WS2812B-кольцах.

Исходная техническая база — ColorMusic AlexGyver, но проект адаптируется под фактически имеющиеся у владельца компоненты. Цель — не покупать новые платы без необходимости.

## 2. Главный принцип

Проектируем от реального наличия:

`инвентаризация → идентификация → проверка характеристик → архитектура → питание → распиновка → прошивка → управление → BOM → закупка только недостающего → стенд → интеграция в лампы`.

Инвентаризация и основные subsystem hardware tests закрыты. С 2026-10-01 проект находится на этапе финализации v1 по `FINALIZATION_PLAN.md`: одна полная Nano release-сборка, одна полная ESP release-сборка, затем завершение Android-приложения, дизайн, двухкольцевой силовой тест и монтаж.

## 7. Текущая рабочая архитектура

`мобильное приложение → домашний Wi‑Fi → ESP8266 → UART → Arduino Nano → MAX9814 / DS3231 / два WS2812B-кольца`

- ESP8266 — сетевой шлюз;
- Nano — реальное управление светом, анализом звука и RTC;
- кольца имеют отдельные DATA-линии D6/D7 и показывают синхронный кадр;
- HC-05 остаётся только резервной деталью, не частью финальной архитектуры.

## 8. Новый интерфейс управления

Старый `Ardublock2.aia` (`LumpV3.1`) уже разобран.

Главный вывод: старое Bluetooth-приложение используем как функциональный референс, но не сохраняем его протокол и схему соединения.

Новый внешний API:

- локальный HTTP;
- Station как основной режим Wi‑Fi;
- при недоступном домашнем роутере — защищённый fallback SoftAP `ARDU-DIRECT` на `192.168.4.1`; Интернет/облако не требуются;
- приложение при подключении читает актуальное состояние устройства.

## 9. Функциональные разделы

Новая лампа имеет пять пользовательских разделов:

1. Обычный свет;
2. Светомузыка;
3. Фон;
4. Ночник;
5. Будильник/рассвет.

Цветная подсветка ColorMusic перенесена из музыкальных режимов в фоновые эффекты.

Подробный состав режимов: `04_Прошивка/РЕЖИМЫ_РАБОТЫ.md`.

## 11. Текущий следующий шаг

1. **Nano R3 P11 slight-low-speed tune (D-115): source/CI PASS, физическая загрузка ещё не подтверждена.** Владелец положительно оценил реальное P11 «Дыхание» на предыдущей R2 и попросил чуть замедлить минимум. Новый полный отдельный `04_Прошивка/nano_ambient12_v3/nano_ambient12_v3.ino` (boot `ARDU1 4`) делает цикл P11 при dynamics=0 ~20,2 c вместо ~16,4; максимум 255 остаётся ~4,1 с; остальные 11 пресетов и EEPROM/UART/ESP/Android не меняются. Откат — прежний полный R2.
2. **CI:** [Arduino Verify https://github.com/dronrome1245/ARDU/actions/runs/37971273171](https://github.com/dronrome1245/ARDU/actions/runs/37971273171) PASS. Компиляция R3: **29376/30720 Flash, 1286/2048 global SRAM** (+40B Flash/+0B SRAM к R2); худший runtime stack и фактическая скорость R3 на кольце ещё не проверены.
3. **Следующий gate владельца:** `cd C:\ARDU` → `git pull` → Arduino IDE открыть `nano_ambient12_v3/nano_ambient12_v3.ino`, Nano/ATmega328P Old Bootloader, Verify, безопасный USB Upload после временного отсоединения ESP TX→Nano D0 **при снятом питании** → Serial `ARDU1 4`, вернуть провод и проверить P11 на одной 44-LED ленте при 0/128/255. Инструкция `04_Прошивка/AMBIENT12_BREATHING_R3_TEST.md`.
4. Остаются открыты: worst-case SRAM stack, 44+44 power/current/temperature, ARDU-DIRECT, остальные 12 сцен на реальном железе. Лимит ≤3000 мА до силового gate. Android 0.22.9 Online/Offline владелец уже подтвердил; его не перепрошивать ради P11.

## 12. База ColorMusic/FHT

Музыкальный тракт ARDU сверяется прежде всего с поздней официальной AlexGyver ColorMusic; рабочий основной референс — `colorMusic_v2.10.ino`. Точная upstream FHT хранится в `04_Прошивка/libraries/FHT/`; не заменять её другой FHT-библиотекой без отдельного решения. Каталог исходных названий: `08_Исходники_и_референсы/AlexGyver_ColorMusic_ОРИГИНАЛЬНЫЕ_ПРОШИВКИ.md`.
