# Видение и цели

## Продукт

Круглая потолочная лампа, которая совмещает обычное освещение, декоративные эффекты и светомузыку, реагирующую на звук в комнате.

## Основной пользовательский сценарий

Пользователь включает музыку на любом внешнем источнике. Микрофон MAX9814 внутри лампы снимает звук помещения. Arduino Nano анализирует громкость/частоты и управляет лентой WS2812B. Режимы и параметры переключаются из мобильного приложения по Wi‑Fi через ESP8266.

## Цели

1. Не требовать проводного аудиовхода от источника музыки.
2. Управлять лампой со смартфона.
3. Использовать уже имеющееся оборудование и не делать покупку ESP32 обязательной.
4. Сохранить полезные режимы AlexGyver ColorMusic.
5. Сохранить и развить уже начатую мобильную логику проекта.
6. Добавить обычный свет, ночник и будильник-рассвет.
7. Сделать архитектуру модульной: связь не должна быть жестко связана с алгоритмами светомузыки.

## Не является целью текущей фазы

- воспроизведение аудио самой лампой;
- передача музыкального аудиопотока по Wi‑Fi;
- облачный сервис;
- управление через интернет вне локальной сети;
- перенос всей логики на ESP8266 до проверки базовой двухконтроллерной схемы.

## Ключевые принципы

### Локальная работа

Светомузыка должна продолжать работать на Nano независимо от временного обрыва Wi‑Fi. Связь нужна для управления, а не для обработки аудиопотока.

### Повторное использование

Алгоритмы AlexGyver ColorMusic рассматриваются как база для режимов VU, частотной цветомузыки и спектра. Сторонний код переносится только с соблюдением лицензии.

### Совместимость команд

Переход Bluetooth → Wi‑Fi не должен без необходимости менять пользовательские команды. Меняется транспорт, а не смысл управления.

### Безопасность питания

Лента питается отдельно от сигнальной части в пределах подтвержденной схемы. Общая земля и уровни логики должны быть проверены до интеграционного теста.

## Критерии готового продукта

- лампа управляется из приложения по Wi‑Fi;
- обычный свет работает независимо от музыкальных режимов;
- микрофон корректно реагирует на музыку в помещении;
- основные режимы ColorMusic визуально работают на круглой ленте;
- настройки не сбрасываются после обычного перезапуска;
- будильник-рассвет работает по DS3231;
- после пропадания Wi‑Fi локальные режимы не зависают;
- после восстановления Wi‑Fi управление возобновляется без перепрошивки.
