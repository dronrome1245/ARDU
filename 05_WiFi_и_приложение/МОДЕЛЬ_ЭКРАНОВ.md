# Модель экранов мобильного приложения ARDU

Версия: 0.1  
Дата: 2026-09-06

## 1. Навигация

Вместо пяти отдельных Bluetooth-экранов старого LumpV3.1 делаем одно приложение с единым соединением и четырьмя рабочими разделами.

```text
Главная
├── Светомузыка
├── Фон
├── Ночник
├── Будильник
└── Настройки
```

## 2. Главная

Показывает:

- связь: `Онлайн / Нет связи`;
- текущий раздел;
- программный ВКЛ/ВЫКЛ;
- четыре крупные кнопки разделов;
- если идёт рассвет — отдельную кнопку `Остановить рассвет`.

На главной не нужны технические данные вроде MAC/IP/HC-05.

## 3. Светомузыка

Структура:

- ВКЛ/ВЫКЛ;
- карточка выбора режима M01–M09;
- при наличии — выбор подрежима;
- `Яркость эффекта`;
- `Фоновая яркость`;
- динамические параметры режима;
- `Калибровка микрофона`.

Пример динамики:

- M01: показывать `Плавность`;
- M02: `Плавность`, `Скорость радуги`;
- M03/M04: `Плавность`, `Чувствительность`;
- M05: `Подрежим`, `Плавность`, `Чувствительность`;
- M06: `Плавность вспышек`, `Частота`;
- M08: `Подрежим`, `Скорость`, `Чувствительность`;
- M09: `Шаг цвета`, `Цвет`.

## 4. Фон

- ВКЛ/ВЫКЛ;
- F01 Постоянный цвет;
- F02 Плавная смена цвета;
- F03 Бегущая радуга;
- параметры текущего эффекта;
- автоперебор;
- период автоперебора.

## 5. Ночник

- ВКЛ/ВЫКЛ;
- цвет;
- насыщенность;
- яркость;
- расписание — второй этап.

## 6. Будильник

- ВКЛ/ВЫКЛ;
- время;
- длительность рассвета;
- максимальная яркость;
- начальный цвет;
- конечный цвет;
- синхронизация RTC с телефоном;
- состояние RTC;
- `Остановить рассвет`.

## 7. Настройки

Обычные:

- имя лампы;
- Wi‑Fi;
- переподключение/первичная настройка;
- версия.

Сервисные:

- тест кольца A;
- тест кольца B;
- тест микрофона;
- состояние RTC;
- состояние Nano;
- диагностика ESP8266.

## 8. Правило UX

Приложение всегда сначала читает состояние лампы, затем рисует интерфейс. Локальные значения телефона не считаются истинными после повторного подключения.
