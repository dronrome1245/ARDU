# 02 — СЛЕДУЮЩИЙ ШАГ

> Совместимый handoff-файл. Канонический статус находится в `STATUS.md`.

## Цель следующей итерации

Закрыть инвентаризацию имеющихся компонентов до формирования списка покупок и до сборки ESP8266-стенда.

## Сейчас

Пользователь продолжает присылать фотографии/маркировки деталей.

Для каждой новой позиции:

1. идентифицировать компонент без догадок;
2. зафиксировать количество только если оно подтверждается;
3. занести в `02_Наши_детали/ИНВЕНТАРЬ.md`;
4. определить роль: `основа / стенд / резерв / проверить / не нужен`;
5. если компонент относится к финальной лампе, синхронизировать `02_КОМПОНЕНТЫ_BOM.md`;
6. не рекомендовать покупку аналога, пока существующий компонент не проверен.

## После завершения фотоинвентаризации

1. Проверить YP-8 AMS1117-3.3 мультиметром.
2. Подтвердить номинал/напряжение электролита порядка 1000 мкФ.
3. Проверить наличие нужных резисторов для DATA WS2812B и согласования Nano → ESP8266.
4. Проверить Dupont-провода и инструмент.
5. Зафиксировать число LED и длину ленты.
6. Составить таблицу электрической совместимости.
7. Сформировать **минимальный** список того, чего действительно не хватает.

## Следующая техническая итерация после инвентаря

Только затем собрать proof-of-concept:

`телефон/ПК → Wi‑Fi → ESP8266 → UART → Nano`

с проверкой питания ESP8266, прошивки и `PING/PONG`.

## Что пока не делать

- Не покупать ESP32.
- Не покупать новый стабилизатор 3,3 В до проверки YP-8.
- Не покупать конденсатор 1000 мкФ до проверки имеющегося.
- Не покупать USB-UART до проверки доступных способов прошивки через имеющиеся платы/оборудование.
- Не подключать ESP8266 к 5-вольтовой логике без согласования уровней.
