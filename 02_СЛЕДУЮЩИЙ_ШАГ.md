# 02 — СЛЕДУЮЩИЙ ШАГ

> Совместимый handoff-файл. Канонический статус находится в `STATUS.md`.

## Цель следующей итерации

Подтвердить питание и физическую разводку двух потолочных корпусов, затем собрать первый ESP8266↔Nano стенд.

## Уже закрыто

- запас WS2812B подтверждён: 5 м;
- `Ardublock2.aia` разобран;
- режимы и параметры v1 определены;
- модель нового Wi‑Fi приложения определена;
- предварительный HTTP API создан.

## От владельца нужны три группы данных

1. Есть ли мультиметр и паяльник/припой.
2. Расстояние между двумя круглыми корпусами и фактическая потолочная проводка: где разветвляется линия второй клавиши, сколько жил приходит к каждому корпусу.
3. Где можно безопасно и обслуживаемо разместить общий S-30-5.

## Затем измерить

1. S-30-5: V+↔V- без нагрузки.
2. YP-8: 5 В на VIN → VOUT без нагрузки.
3. После подтверждения 3,3 В — YP-8 с ESP8266 под Wi‑Fi нагрузкой.
4. Прочитать маркировку и количество электролитов около `1000 µF`.
5. Собрать делитель Nano TX → ESP RX и измерить его выход до подключения ESP8266.

## Параллельная подготовка

- удалить `201` на DS3231 перед штатным питанием с CR2032;
- проверить способ прошивки ESP8266 через имеющийся Nano/другой мост;
- физически примерить 43 LED на кантик 71,5 см;
- не замыкать DOUT последнего LED обратно на DIN первого.

## После этого

1. утвердить окончательный BOM;
2. собрать `S-30-5 → Nano + YP-8/ESP8266 → UART → одно кольцо`;
3. добиться `PING/PONG`;
4. включить F01 постоянный цвет по Wi‑Fi;
5. добавить второе кольцо;
6. подключить MAX9814 и реализовать M01 VU градиент.

Подробный порядок: `04_Прошивка/ПОРЯДОК_РЕАЛИЗАЦИИ.md`.


## Актуальный следующий шаг 2026-09-20

Собрать безопасный низкоомный programmer-divider `750 Ом / 1,5 кОм` из имеющихся резисторов 1,5 кОм, оставить `100 µF 10 V` у ESP, проверить HIGH около 3,3 В и повторить upload на `115200` с ручным кратким `RST→GND` во время `Connecting...`. Прямой D0→ESP RX больше не использовать как штатный способ.


## Актуальный следующий шаг — FW-0 Nano

1. Полностью отделить Nano от ESP по D0/D1 на время загрузки FW-0.
2. Убрать перемычку `RESET Nano → GND` — она нужна была только когда Nano работала USB↔UART-мостом.
3. Оставить Nano подключённой только по USB к компьютеру и загрузить `04_Прошивка/nano_fw0/nano_fw0.ino`.
4. Открыть Serial Monitor `115200`, окончание строки `Newline`; ожидать `ARDU NANO FW0 READY`.
5. Отправить `PING` → ожидать `PONG`; затем `STATUS` → ожидать строку `STATUS FW=FW0 ...`.

До успешного теста кольцо, ESP и MAX9814 к FW-0 не подключать.


### Уточнение после первой попытки FW-0

Перед повторным Upload Nano: ESP должен быть полностью отключён от `D0` и `D1`; перемычка `RESET Nano→GND` снята; Serial Monitor закрыт. Повторить upload с текущими настройками Arduino IDE. Только если `not in sync` сохранится на полностью изолированной Nano, проверять вариант `ATmega328P (Old Bootloader)` и ручной reset.


### Следующий тест Nano после сохранения `resp=0x41`

В Arduino IDE выбрать `Tools → Processor → ATmega328P (Old Bootloader)` и повторить Upload при полностью свободных D0/D1 и снятом `RESET→GND`. Если ошибка сохранится — выполнить ручной reset Nano в момент начала загрузки.


## Актуальный следующий шаг — FW-1

FW-0 закрыт. Оставить Nano изолированной от ESP, выбрать `Arduino Nano → ATmega328P (Old Bootloader)`. Открыть `04_Прошивка/nano_fw1/nano_fw1.ino` и сначала выполнить только Verify/Compile. Если Arduino IDE сообщает, что `FastLED.h` не найден, установить библиотеку `FastLED` через Library Manager. Кольцо пока не подключать. После успешной компиляции перейти к физической схеме одного кольца на D6.


### FW-1 — физический тест одного канала

Собрать только Nano + один вход WS2812B: Nano питается по USB; лента питается от S-30-5 5 В; земли Nano и S-30-5/ленты объединены; `Nano 5V` с `S-30-5 V+` не соединять. DATA: D6 → DIN начала ленты; предпочтительно через 330 Ом, а для текущего короткого стенда допустим временный последовательный 1,5 кОм из наличия. Проверять первые 43 LED на малой яркости/лимите 500 мА. Второе кольцо, ESP и MAX9814 не подключать.
